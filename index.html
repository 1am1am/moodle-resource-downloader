Nén trọn bộ thành file .ZIP

Mặc định gom tất cả slide, bài giảng, đề thi vào 1 file zip duy nhất đặt tên theo môn học.

🎯

Nút nổi trực tiếp trên trang Moodle

Tự động xuất hiện nút [📥 Tải tài liệu] ngay góc màn hình khóa học, không cần thao tác phức tạp.

🔒

Giữ nguyên phiên đăng nhập

Chạy trực tiếp với cookie session của bạn trên Chrome, không cần nhập lại mật khẩu hay lo lỗi CAS/SSO.

⚡

Tùy chọn tải riêng từng file

Nếu không muốn nén zip, bạn chỉ cần bỏ tick chọn ZIP để tải từng file vào thư mục máy tính.

🛡️

Chống chặn spam tải

Cơ chế tải thông minh có giãn cách nhẹ để không làm sập tab hay bị hệ thống Moodle giới hạn.

Hướng dẫn cài đặt Chrome Extension (3 bước)

1

Tải và giải nén tệp Extension

Bấm nút "Tải Extension về máy (.ZIP)" ở trên và giải nén file ZIP ra một thư mục trên máy tính.

2

Mở trang quản lý Tiện ích trên Chrome

Nhập chrome://extensions vào thanh địa chỉ và bật công tắc Developer mode (Chế độ cho nhà phát triển) ở góc trên bên phải.

3

Tải tiện ích đã giải nén

Bấm nút Load unpacked (Tải tiện ích đã giải nén) và chọn thư mục bạn vừa giải nén ở bước 1. Xong!
